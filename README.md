# Generative AI

## A Brief Introduction

We built an AI named Xiao Zhi mostly based on C language.Challenges are met because of low performance of IDE we used:BorlandC.To solve this problem,we created new methods to create conversations!

Firstly we use MI to cut a sentence into pieces.The training data and training codes are kept in the folder \train.Most of our training data is from zhihu and ruozhiba.Here's how it runs.

<img width="510" height="387" alt="image" src="https://github.com/user-attachments/assets/532a4657-ce99-401f-8f0e-261c9d2a797e" />

We then created a new data structure called strengthened lexicographic tree and a new definition called fusing inheritation.The theory is based on a fundamental assumption of language and it can simulate our brain's memory,logical reasoning,inductive reasoning and analogic reasoning,taking speed of thinking into consideration.The image of our data structre is here:

We then set abstract tabs for symbols of natural language to transform into machine language.Our system supports different forms of grammar,and emotions in sentences.

<img width="431" height="342" alt="image" src="https://github.com/user-attachments/assets/d16dae0a-eea9-4f57-9b08-73cbcc850b4c" />

We then built a file system,using the file system we optimised time complexity,it finds and finally shows the result of conversation.

<img width="511" height="399" alt="image" src="https://github.com/user-attachments/assets/449461f7-eafd-4669-9223-569bafb1ea70" />

As for images,we use SVGA--65536 colors, coding Bresenham algorithm, Bezier curve and procedure for inside filling.That sets the base for drawing.We then drew some images using anything above.Then we created algorithms to overlay,spin,resize,change color,move and choose the curve to be filled or not.If you choose to open the overlapping mode,it will overlap and if you switch it off,it won't.We also have an option to clear off the image.The images can be changed into many modes.

We have other Easter Eggs such as an ability to calculate decimals,warn a question to be raised beforehand,the first BFS and its query stack related(but failed due to low capacity of our IDE),a warning for bad languages and so on.You can explore all of these by yourself!
